# Sample fixtures (fictional)

Everything here is made-up sample data for building and testing the UI. It is not the
output of any PixelProof analysis.

- `sample-files.generated.ts` is generated by `scripts/gen-fixtures.py`. The hunks are real
  `difflib` output over the before/after sources embedded in that script.
- `public/fixtures/acme-settings-{before,after}.png` are drawn by `scripts/gen-fixture-images.py`.
  The PNGs are the source of truth; see the script's docstring for the four deliberate
  differences, which serve as ground truth when M2's analysis is tested.
